# Practice: Acid–base reactions and mixtures

Assume 25 °C. Use Kb(NH₃) = 1.8 × 10⁻⁵, which makes pKa(NH₄⁺) = 14.00 − 4.74 = 9.26. Try each problem before opening the solution.

---

**1.** 30.0 mL of 0.150 M HNO₃ is mixed with 20.0 mL of 0.200 M KOH. What is the pH of the mixture?

<details><summary>Show solution</summary>

```
mmol H₃O⁺ = 30.0 × 0.150 = 4.50        mmol OH⁻ = 20.0 × 0.200 = 4.00
Excess H₃O⁺ = 0.50 mmol in 50.0 mL total = 0.010 M
pH = 2.00
```

</details>

---

Problems 2–4 use the same starting solution, **40.0 mL of 0.100 M NH₃**, with different volumes of 0.100 M HCl added. Notice how the method changes each time.

**2.** Calculate the pH after adding 20.0 mL of 0.100 M HCl.

<details><summary>Show solution</summary>

```
              NH₃  +  H₃O⁺  →  NH₄⁺  +  H₂O
Before (mmol) 4.00    2.00       0
After         2.00    0          2.00
```

Both NH₃ and NH₄⁺ are present, so this is a buffer. Use the pKa of the acid in the pair, NH₄⁺:

```
pH = pKa + log([NH₃]/[NH₄⁺]) = 9.26 + log(2.00/2.00) = 9.26
```

This is the half-equivalence point, which is why pH = pKa (folder 4).

</details>

---

**3.** Calculate the pH after adding 40.0 mL of 0.100 M HCl.

<details><summary>Show solution</summary>

All 4.00 mmol of NH₃ become NH₄⁺, and there's no excess HCl. What's left is a weak acid:

```
[NH₄⁺] = 4.00 mmol / 80.0 mL = 0.0500 M
Ka     = Kw / Kb = 1.0 × 10⁻¹⁴ / 1.8 × 10⁻⁵ = 5.6 × 10⁻¹⁰
[H₃O⁺] = √(5.6 × 10⁻¹⁰ × 0.0500) = 5.3 × 10⁻⁶ M
pH = 5.28
```

The solution is acidic, as expected at the equivalence point of a weak base with a strong acid.

</details>

---

**4.** Calculate the pH after adding 50.0 mL of 0.100 M HCl.

<details><summary>Show solution</summary>

```
mmol H₃O⁺ added = 5.00; 4.00 react with NH₃, so 1.00 mmol is left over
[H₃O⁺] = 1.00 mmol / 90.0 mL = 0.0111 M
pH = 1.95
```

The NH₄⁺ (a very weak acid) adds almost nothing next to the excess strong acid.

</details>

---

**5.** Write the net ionic equation for each reaction. Use → for reactions that go to completion and ⇌ for equilibria.

(a) aqueous HF + aqueous NaOH
(b) aqueous NH₃ + aqueous HCl
(c) aqueous HNO₃ + aqueous KOH
(d) aqueous HNO₂ + aqueous NH₃ (Ka of HNO₂ = 4.5 × 10⁻⁴). Also calculate K and say whether products are favored.

<details><summary>Show solution</summary>

(a) HF(aq) + OH⁻(aq) → F⁻(aq) + H₂O(l). HF is weak, so it stays as a molecule. Na⁺ is a spectator.

(b) NH₃(aq) + H₃O⁺(aq) → NH₄⁺(aq) + H₂O(l). You can also write NH₃ + H⁺ → NH₄⁺. Cl⁻ is a spectator.

(c) H₃O⁺(aq) + OH⁻(aq) → 2 H₂O(l). K⁺ and NO₃⁻ are spectators.

(d) HNO₂(aq) + NH₃(aq) ⇌ NO₂⁻(aq) + NH₄⁺(aq)

```
K = Ka(HNO₂) × Kb(NH₃) / Kw = (4.5 × 10⁻⁴)(1.8 × 10⁻⁵) / 1.0 × 10⁻¹⁴ = 8.1 × 10⁵
```

K ≫ 1, so **products are favored**. HNO₂ (Ka = 4.5 × 10⁻⁴) is a much stronger acid than NH₄⁺ (Ka = 5.6 × 10⁻¹⁰).

</details>

**6.** Which of the following mixtures, each in 1.0 L of solution, is a buffer?

(A) 0.10 mol HCl + 0.10 mol NaCl
(B) 0.10 mol CH₃COOH + 0.050 mol NaOH
(C) 0.10 mol CH₃COOH + 0.10 mol NaOH
(D) 0.10 mol NH₃ + 0.20 mol HCl

<details><summary>Show solution</summary>

**(B).** After the reaction it contains 0.050 mol CH₃COOH and 0.050 mol CH₃COO⁻, both members of a weak conjugate pair.
- (A) HCl is a strong acid and Cl⁻ has no basic properties, so there's no weak pair.
- (C) All the acid is converted, leaving only CH₃COO⁻.
- (D) The HCl is in excess, leaving NH₄⁺ plus extra strong acid.

</details>

---

**7.** Equal numbers of moles of formic acid (HCOOH) and NaOH are mixed. Which best describes the resulting solution?

(A) pH = 7, because the acid has been neutralized
(B) pH > 7, because HCOO⁻ reacts with water to produce OH⁻
(C) pH < 7, because HCOOH is in excess
(D) pH < 7, because Na⁺ reacts with water to produce H₃O⁺

<details><summary>Show solution</summary>

**(B).** After the reaction, the solution contains Na⁺ (a spectator) and HCOO⁻, the conjugate base of a weak acid. HCOO⁻ + H₂O ⇌ HCOOH + OH⁻ makes the solution slightly basic.

</details>

**8. (Free-response style)** A student mixes 25.0 mL of 0.200 M CH₃COOH (Ka = 1.8 × 10⁻⁵) with 25.0 mL of 0.100 M NaOH.

(a) Write the net ionic equation for the reaction that occurs.

(b) Calculate the number of moles of CH₃COOH and CH₃COO⁻ present after the reaction.

(c) Calculate the pH of the resulting solution.

(d) The student says the solution is a buffer. Do you agree? Justify your answer.

<details><summary>Show solution</summary>

(a) CH₃COOH(aq) + OH⁻(aq) → CH₃COO⁻(aq) + H₂O(l)

(b)
```
mol CH₃COOH initial = 0.0250 L × 0.200 M = 5.00 × 10⁻³ mol
mol OH⁻ added       = 0.0250 L × 0.100 M = 2.50 × 10⁻³ mol
After: CH₃COOH = 2.50 × 10⁻³ mol,  CH₃COO⁻ = 2.50 × 10⁻³ mol
```

(c) pH = pKa + log(2.50 × 10⁻³ / 2.50 × 10⁻³) = pKa = −log(1.8 × 10⁻⁵) = **4.74**

(d) **Agree.** The solution contains significant amounts of both a weak acid (CH₃COOH) and its conjugate base (CH₃COO⁻). The CH₃COOH can neutralize added OH⁻, and the CH₃COO⁻ can neutralize added H₃O⁺, so the pH changes only a little when either is added.

</details>
