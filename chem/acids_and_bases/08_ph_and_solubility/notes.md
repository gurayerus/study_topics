# 8. pH and solubility

AP topic **8.11 pH and Solubility** (topic 7.13 in course editions before fall 2024)

> **Goal:** Predict, qualitatively, whether changing the pH will make a salt more or less soluble, and explain why with Le Châtelier's principle.

**Only the qualitative effect is tested.** The AP exam won't ask you to calculate solubility at a given pH. It builds on **7.11 (solubility equilibria and Ksp)** and **7.12 (the common-ion effect)**, so review those first if needed.

## The rule

A salt's solubility depends on pH **when one of its ions is a weak base, a weak acid, or OH⁻**.

| The salt's anion is… | Lowering pH (adding acid) | Examples |
|---|---|---|
| a **basic** anion: OH⁻ or the conjugate base of a weak acid | **increases solubility** | Mg(OH)₂, CaCO₃, CaF₂, Ca₃(PO₄)₂, AgCH₃COO |
| the anion of a **strong** acid: Cl⁻, Br⁻, I⁻ | **no significant effect** | AgCl, AgBr, PbI₂ |

## Why: Le Châtelier

Take CaF₂ as an example:

```
CaF₂(s) ⇌ Ca²⁺(aq) + 2 F⁻(aq)
```

Adding acid supplies H₃O⁺, which reacts with the basic anion F⁻:

```
F⁻(aq) + H₃O⁺(aq) → HF(aq) + H₂O(l)
```

This **removes F⁻** from the solution, so the dissolution equilibrium shifts **right** and more CaF₂ dissolves.

In AgCl, the anion Cl⁻ is the conjugate base of a strong acid. It has no tendency to react with H₃O⁺, so adding acid removes nothing and the equilibrium doesn't shift.

## Raising the pH

For **hydroxides**, adding base works the other way. Extra OH⁻ is a **common ion**, so solubility decreases (7.12):

```
Mg(OH)₂(s) ⇌ Mg²⁺(aq) + 2 OH⁻(aq)      adding OH⁻ shifts left, so less dissolves
```

## Real-world examples

| Situation | Chemistry |
|---|---|
| **Antacids**: Mg(OH)₂ (milk of magnesia) and CaCO₃ (Tums) | Insoluble in water, but they dissolve in stomach acid as they neutralize it. |
| **Acid rain damaging marble and limestone** (CaCO₃) | CO₃²⁻ + H₃O⁺ → HCO₃⁻ + H₂O, and with more acid, H₂CO₃, which breaks down to CO₂ + H₂O. Removing CO₃²⁻ dissolves more CaCO₃. |
| **Tooth decay** | Enamel is hydroxyapatite, Ca₅(PO₄)₃OH. Acids made by bacteria remove OH⁻ and PO₄³⁻, so the enamel dissolves. |
| **Fluoride toothpaste** | Converts some enamel to fluorapatite, Ca₅(PO₄)₃F. F⁻ is a much weaker base than OH⁻, so fluorapatite holds up better in acid. |

## How to write the explanation (free response)

1. Write the dissolution equilibrium.
2. Say which ion reacts with the added H₃O⁺ (or OH⁻), and write that reaction.
3. Say that this removes (or adds) an ion, so the equilibrium shifts right (or left), so solubility increases (or decreases).

## Common mistakes

- **Saying every salt dissolves better in acid.** Salts of strong-acid anions (AgCl, AgBr, PbI₂) aren't affected.
- **Forgetting that OH⁻ is itself a basic anion.** Metal hydroxides become much more soluble in acid.
- **Attempting a calculation.** On the AP exam this topic is qualitative only. Explain with Le Châtelier.
